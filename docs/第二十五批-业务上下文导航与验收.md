# 第二十五批：业务上下文导航与实际页面验收

日期：2026-11-12。目标：以日常稳定使用为准，继续做操作体验收尾，不增加 Docker、Python/Java Runner、登录或权限模块。

## 开发内容

1. 项目管理 `ProjectListView.vue`：在项目操作列增加「查看版本」，路由跳转至 `#/versions?projectId={项目ID}`。
2. 版本管理 `VersionListView.vue`：增加「查看需求」和「测试轮次」，分别跳转 `#/requirements?versionId={版本ID}` 和 `#/test-cycles?versionId={版本ID}`。进入时自动按项目 ID 筛选；新建版本时沿用筛选项目。
3. 需求与详细设计 `RequirementListView.vue`：读取 URL 上合法的 versionId，自动按版本筛选；新增需求时原有功能会沿用当前筛选版本。
4. 测试轮次 `TestCycleListView.vue`：读取 URL 上的 versionId 并自动筛选。新建轮次时自动把当前筛选版本带入表单；用户仍可人工切换版本。
5. 三个筛选页面支持同一路由的查询参数变化：如从 A 项目变为 B 项目，自动更新筛选并重新载入列表，无需整页刷新。
6. 通用 `frontend/src/utils/contextNavigation.js`：只允许单值、规范格式的正整数 ID（防止 URL 多值、空值、指数格式、前导零等被错误解析）；上下文链接仅允许项目→版本或版本→需求/轮次，不支持任意模块传递未经检查的查询参数。
