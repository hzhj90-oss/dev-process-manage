# 测试报告模块开发记录

## 1. 功能范围

测试报告基于测试轮次创建时保存的不可变快照生成，不重新读取当前测试用例、需求、详细设计或环境配置，避免历史报告因源数据后续修改而变化。

本模块只生成 HTML，不新增数据库表、字段或迁移版本。报告支持浏览器查看、下载 HTML，以及浏览器打印/另存为 PDF。

## 2. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/test-cycles/{id}/report` | 浏览器内联查看 HTML 报告 |
| GET | `/api/test-cycles/{id}/report?download=true` | 下载 HTML 报告 |

响应使用 UTF-8 `text/html`，设置 `Cache-Control: no-store` 和 `X-Content-Type-Options: nosniff`。下载文件名为 `test-cycle-{id}-report.html`。

报告内附件链接使用当前请求上下文生成绝对地址，下载的 HTML 在应用可访问时仍可打开附件；附件文件本身不嵌入 HTML。

## 3. 报告内容

### 3.1 轮次信息

- 项目、版本、轮次名称及轮次编号。
- 轮次状态、测试阶段、开始时间、完成时间。
- 环境名称、环境类型、环境地址、API 地址、认证方式。
- 环境配置快照（脱敏）、代码版本、Git 分支、Git Commit、构建编号。
- 测试范围、轮次说明和统计结果。

### 3.2 用例与覆盖关系

- 用例编号、标题、修订版本、执行方式、最新结果。
- 前置条件、步骤、每步预期结果及操作数据、整体预期结果。
- 测试数据快照、ChatGPT 执行指令。
- 关联需求编号、标题、覆盖类型，以及需求内容快照。
- 关联详细设计的修订版本、标题和设计内容快照。

### 3.3 执行记录

- 每次执行的 attempt 编号、Runner 类型、状态、结果、执行人和起止时间。
- 实际结果、执行日志。
- 证据附件名称、类型、大小和下载链接。
- 执行事件，包括断言事件、检查点和人工介入相关记录。

整轮父任务会展开为用例子任务；单用例任务直接读取自身执行记录。分页查询只处理当前轮次，并跳过子任务在分页结果中的重复行。

## 4. 安全处理

- 所有动态 HTML 内容均进行 HTML 转义，避免测试数据、日志或需求文本注入脚本。
- JSON 快照递归检查敏感字段名，覆盖 password、token、authorization、cookie、secret、api key、private key、credential 等字段。
- JSON 字符串和普通文本继续检查 Bearer/Basic Authorization 头及 password/token/secret 等键值对，防止敏感内容藏在说明、指令、Markdown 或嵌套 JSON 字符串中。
- 凭据引用字段也按敏感字段处理，不在报告中输出其实际值。
- 报告响应不缓存；附件下载仍由原附件接口执行任务、执行记录和附件归属校验。

## 6. 自动化测试

### TestReportServiceTest

1. 验证轮次、环境、范围、用例步骤、需求覆盖、详细设计、执行结果、事件及附件均能生成。
2. 验证父任务下的子任务执行记录能正确归属到用例。
3. 验证历史轮次缺少环境快照时仍能生成报告。
4. 验证 HTML 注入字符串会被转义。
5. 验证 JSON 字段、嵌套配置、普通文本、Bearer Token 和 Markdown 中的敏感内容均被脱敏。
6. 验证附件链接支持相对地址和基于当前上下文的绝对地址。

### TestReportControllerTest

1. 默认返回内联 HTML。
2. `download=true` 返回附件下载头。
3. 验证响应为 HTML、禁止缓存并设置 `nosniff`。
