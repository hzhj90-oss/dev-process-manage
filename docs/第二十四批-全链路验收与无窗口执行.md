## 一、Windows 后台执行问题

用户反馈：每次通过 Tunnel 启动 CMD/PowerShell 时仍有终端窗口弹出，影响正常使用电脑。

实际检查：

- Desktop Commander Tunnel 的安装代码 `terminal-manager.js` 已配置 `spawnOptions.windowsHide = true`，说明 Tunnel 直接管理的子进程按隐藏窗口方式启动。
- 现有 Java、HTTP/Node/Browser Runner 启动脚本本身也均使用 `Start-Process -WindowStyle Hidden`。
- 但 **Windows 任务计划程序的两个原始注册动作**未设置隐藏窗口：`DPM-DevProcessManager-Watchdog`（约每分钟执行一次）与 `DPM-DevProcessManager-DatabaseBackup`（登录/每日 02:30）。它们可能独立于本次开发调用造成 PowerShell 弹窗。

本次修正：
1. 修改 `scripts/install-service-watchdog.ps1` 和 `scripts/install-database-backup.ps1`，注册动作增加 `-WindowStyle Hidden`。
2. 对**现有已注册任务**执行 Set-ScheduledTask，仅替换 PowerShell Action 参数，保留定时触发、用户权限和其他配置。
3. 重新读取已注册的两个任务，确认两者实际 Action 均包含 `-NoProfile -NonInteractive -WindowStyle Hidden -ExecutionPolicy Bypass`。
4. 开发命令仍通过 Tunnel 执行（源码已确认 windowsHide=true），文件读写优先使用 Desktop Commander 文件工具，避免不必要的外部进程和服务重启。

**验证限制**：能够证实注册任务参数和 Tunnel 的隐藏窗口选项，无法仅凭远程命令输出直接观察用户屏幕是否还有瞬时闪窗。若未来仍出现弹窗，应优先核查其他计划任务、控制台子进程或第三方启动器，而不是反复盲目执行新命令。手动双击 `start.cmd` 属于用户交互脚本，仍可能显示窗口，不在本次无头后台任务修正范围。
