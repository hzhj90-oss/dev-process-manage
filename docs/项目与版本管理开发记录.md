# 项目管理与版本管理（第一阶段）

## 1. 本阶段范围

将初始化数据库中的 dpm_project、dpm_version 两张表接入真实业务接口和前端页面。
本阶段不修改数据库结构，不新增迁移脚本。

## 2. 项目管理

页面：/#/projects

API：
- GET /api/projects：分页查询，支持 keyword、status、pageNum、pageSize。
- GET /api/projects/{id}：项目详情。
- POST /api/projects：新增项目。
- PUT /api/projects/{id}：编辑项目。

字段：项目编码、项目名称、仓库地址、主分支、状态、说明。
项目编码全局唯一；项目状态为 ACTIVE / INACTIVE。
不提供物理删除，避免项目版本及后续需求、测试历史因级联删除丢失。

## 3. 版本管理

页面：/#/versions

API：
- GET /api/versions：分页查询，支持 projectId、keyword、status、pageNum、pageSize。
- GET /api/versions/{id}：版本详情。
- POST /api/versions：新增版本。
- PUT /api/versions/{id}：编辑版本。

字段：所属项目、版本号、版本名称、状态、计划开始日期、计划发布日期、发布时刻、说明。
同一项目内版本号唯一；不同项目允许使用相同版本号。
版本必须关联一个项目；新增/编辑时校验所属项目存在且启用。
计划开始日期不能晚于计划发布日期。
版本状态：PLANNING、DEVELOPING、TESTING、RELEASED、ARCHIVED。
进入 RELEASED 状态时自动记录 released_at。

## 4. 查询展示

- 项目分页返回版本数量。
- 版本分页返回所属项目编码/名称、需求数量、测试轮次数量。
- 需求数量和测试轮次数量通过关联表统计，暂未创建业务数据时显示 0。
- 分页大小由服务端限制在 1~100。

## 5. 前端组织

- src/api/http.js：统一 Axios 请求实例。
- src/api/projects.js：项目 API。
- src/api/versions.js：版本 API。
- src/router/index.js：Hash 路由。
- src/views/ProjectListView.vue：项目管理页面。
- src/views/VersionListView.vue：版本管理页面。
- src/views/DashboardView.vue：概览统计和模块入口。
