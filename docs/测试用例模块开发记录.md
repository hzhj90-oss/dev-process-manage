# 测试用例模块开发记录

## 1. 本阶段范围

完成测试用例主数据、用例修订历史、步骤维护、需求覆盖关系，以及为后续自动执行预留的执行配置。

本阶段不实现测试轮次和脚本运行引擎。固定脚本的执行、ChatGPT 工具调用、人工介入与执行证据将在后续阶段完成。

## 2. 数据库设计

复用初始数据库脚本 `database/migrations/V1.0.0__initial_schema.sql` 中已创建的表，本阶段没有新增 DDL，也没有修改已应用的初始迁移。

| 表 | 用途 |
|---|---|
| `dpm_test_case` | 用例主数据：编号、名称、状态、当前修订号、负责人 |
| `dpm_test_case_revision` | 不可变的用例内容修订：前置条件、步骤 JSON、整体预期、类型、优先级、执行方式、脚本/AI 配置、测试数据、修订说明 |
| `dpm_requirement_case` | 用例与需求的多对多覆盖关系 |
| `dpm_test_script` | 固定脚本主数据：编号、名称、启停状态和当前修订指针 |
| `dpm_test_script_revision` | 固定脚本不可变修订：语言、运行时、来源、源码/路径、入口、参数和修订说明 |

### 2.1 修订规则

1. 创建用例时生成 V1。
2. 编辑用例时不覆盖历史修订，而是新增 V(n+1)。
3. 主表的 `current_revision_no` 指向当前修订。
4. 修订号通过事务内锁定用例主记录后递增，避免并发编辑产生相同修订号。
5. 修订详情按 `test_case_id + revision_id` 查询，不能读取其他用例的修订。
6. 需求关联关系保存当前覆盖范围；用例内容的历史快照由修订表保存。创建测试轮次时，系统会把当时的需求覆盖关系、需求正文和最新详细设计修订一并写入轮次快照。

### 2.2 字段约定

- 用例状态：`ACTIVE`、`INACTIVE`。
- 用例类型：`FUNCTIONAL`、`REGRESSION`、`INTEGRATION`、`API`、`UI`、`PERFORMANCE`、`SECURITY`、`OTHER`。
- 优先级：`LOW`、`MEDIUM`、`HIGH`、`URGENT`。
- 执行方式：
  - `MANUAL`：人工执行。
  - `SCRIPT`：关联脚本库中已启用的脚本，必须指定 `scriptId`。
  - `AI`：由 ChatGPT 根据用例动态生成执行逻辑，必须填写 `aiInstruction`，不能同时关联固定脚本。
- 每个用例至少有一个步骤；每个步骤必须填写操作和步骤预期结果。
- `testDataJson` 必须是合法 JSON。
- 用例编号全局唯一。
- 一个用例可以关联多个需求，一个需求也可以被多个用例覆盖。

## 3. 后端接口

统一前缀：`/api/test-cases`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/test-cases` | 分页、关键字及状态/类型/优先级/执行方式筛选 |
| POST | `/api/test-cases` | 创建用例并生成 V1 |
| GET | `/api/test-cases/{id}` | 用例详情，包含当前修订和需求关联 |
| PUT | `/api/test-cases/{id}` | 更新主数据、生成新修订并保存需求关联 |
| GET | `/api/test-cases/{id}/revisions` | 查询修订历史列表 |
| GET | `/api/test-cases/{id}/revisions/{revisionId}` | 查询指定修订完整内容 |
| GET | `/api/test-cases/available-requirements` | 查询可关联需求，可按版本筛选 |
| GET | `/api/test-cases/scripts` | 查询已启用脚本 |

## 4. 前端页面

路由：`/#/test-cases`

功能：
- 用例列表、筛选和分页。
- 新建/编辑用例。
- 动态增加、删除测试步骤。
- 配置人工、固定脚本、ChatGPT 动态执行方式。
- 按版本筛选需求并建立多对多关联。
- 查看修订历史及每个修订的完整步骤、预期结果和 AI 指令。

后续阶段已补充自动化脚本库管理页面和 API，支持脚本新增/编辑、启停及不可覆盖的修订历史。脚本源码目前只登记和保存，不会执行；实际脚本执行仍属于后续 Runner 阶段。

## 6. 后续工作

已在后续阶段完成：
1. 自动化脚本库管理：脚本录入、语言/运行时/入口、启停、修订历史及用例对脚本修订的固定引用。

3. 人工介入状态流转、任务断点恢复和测试报告生成。
