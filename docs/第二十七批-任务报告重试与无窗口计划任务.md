## 一、CMD/PowerShell 窗口偶发闪现：定位和整改

用户反馈之前即使在 PowerShell 定时任务参数中增加 `-WindowStyle Hidden`，电脑仍偶发控制台窗口闪现，干扰当前输入、窗口焦点等操作。

调查发现：Windows 计划任务 `DPM-DevProcessManager-Watchdog` 每分钟执行，动作仍直接为 `powershell.exe`；`DPM-DevProcessManager-DatabaseBackup` 每天 02:30 和登录后执行，同样启动 PowerShell。隐藏窗口参数在 PowerShell 自身启动后才被处理，仍可能出现短暂控制台显示。之前的修改没有改变启动程序本身。

本次真正替换计划任务的可执行文件：

- 新增 `scripts/service-watchdog-hidden.vbs` 和 `scripts/scheduled-backup-hidden.vbs`。使用 **GUI 子系统 `wscript.exe`** 运行 Windows Script Host 脚本，内部用 `WScript.Shell.Run(command, 0, True)` 启动隐藏的 `powershell.exe -NoProfile -NonInteractive -WindowStyle Hidden -ExecutionPolicy Bypass`，等待子进程退出并透传退出码。
- 更新 `scripts/install-service-watchdog.ps1`、`scripts/install-database-backup.ps1`：未来重装/重新注册任务也统一注册为 `wscript.exe //B //NoLogo ...hidden.vbs`，不再恢复原 PowerShell 直接启动方式。
- **已实际更新 Windows 当前注册任务的 Action**，通过 `Set-ScheduledTask -Action` 仅更换启动器，保留原任务的触发时间、账户、权限和调度策略。安全地读取旧动作并在异常时回滚，不中断业务服务。
- 使用 GUI Script Host 试运行守护脚本得到返回值 0。重新读取实际任务结果：守护任务 `Ready`，其最后一次运行在 11:03:06，结果码 0；备份 `Ready`，上次结果 0，下次 2026-11-13 02:30。
- `scripts/service-status.ps1` 和 `scripts/backup-status.ps1` 新增 `WATCHDOG_WINDOWLESS_LAUNCH` / `BACKUP_WINDOWLESS_LAUNCH` 显示是否真正采用窗口不可见的启动器。
- 检查其他 Windows 任务计划程序中频率 1～15 分钟、直接运行 CMD/PowerShell/cscript/wscript 的计划任务，**未发现其它符合这一筛选条件的项目**。这只是计划任务范围内的排查，不等于排除所有软件自己启动短暂 CMD 的可能性。
- 本次没有修改所有全局计划任务、没有禁用守护、没有修改 Windows 全局执行策略，也没有调整 Java 端口、Runner、备份时间或备份策略。

> 验证界限：能够确认 Windows 计划任务启动程序已改为 GUI 子系统且守护正常执行；无法通过仅查询任务状态来客观证实用户屏幕上绝对没有任何其它程序造成的闪窗。若再次发生，应记录发生的具体时间，对照 Windows 进程创建/任务计划日志定位其它来源，不再反复盲改同一组任务。
