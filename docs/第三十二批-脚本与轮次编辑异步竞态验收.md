# 第三十二批：脚本管理与测试轮次编辑异步竞态修复

日期：2026-11-12。仓库：`D:\code\dev-process-manager`。

## 实际问题

- 脚本编辑 `TestScriptListView.openEdit` 在 GET 返回后直接把结果写入表单；快速关闭脚本 A、再编辑脚本 B 时，A 的晚到请求可以覆盖 B。脚本修订历史的列表/详情亦可由旧请求覆盖新选择。
- 测试轮次编辑 `TestCycleListView.openEdit` 在 GET 返回之后才打开编辑框；连续点击不同轮次可能打开错误的记录，也没有原位重试入口。期间保存按钮未明确与详情加载状态关联。
- 版本、需求的普通编辑主要使用列表现有字段，没有相同的详情请求先后竞态；需求详细设计弹窗另行检查。

## 修复

### 脚本列表与历史

- 在 `frontend/src/views/TestScriptListView.vue` 增加 editorGate、editorToken、editorLoading、editorError。编辑时立即打开弹窗并清空旧脚本；响应校验 script id、脚本编号和名称，只有当前弹窗的最新请求可覆盖表单。
- 关闭弹窗和路由卸载使旧请求失效。加载失败保留弹窗并显示「重试读取脚本详情」，失败或加载中不能保存。保存前、异步表单校验结束后均核对会话；保存进行中禁止点击取消或关闭。
- 为修订历史新增 historyGate 与 revisionGate；快速切换脚本或修订时只接受最新响应，并校验修订 ID。历史错误显示并可原位重试。
- 保留后端脚本修订历史和保存规则；未新增脚本语言或执行器。

### 测试轮次编辑

- 在 `frontend/src/views/TestCycleListView.vue` 增加 cycleEditorGate、cycleEditorToken、editorLoading、editorError。
- 打开编辑时先清空旧表单，立即打开弹窗，后台 GET 当前轮次，确保返回轮次 ID 与当前目标一致。加载失败保留弹窗，可「重试读取轮次配置」。
- 加载中/失败时禁用表单与保存；保存前和异步校验结束后检查编辑会话和选项加载完整状态。保存进行中禁止关闭或取消；离开路由使在途请求失效。未改变测试轮次的状态流转、用例快照及执行逻辑。
