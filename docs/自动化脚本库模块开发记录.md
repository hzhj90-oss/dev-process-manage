# 自动化脚本库模块开发记录

## 1. 模块范围

维护可复用的固定自动化脚本配置及不可覆盖的修订历史，并允许测试用例修订绑定某一具体脚本修订。
脚本库负责登记、保存和查询不可变修订。固定脚本执行器已支持 HTTP 只读 DSL 和 NODE 受限 JavaScript（QuickJS WASM）；Python、Java/JUnit、浏览器自动化仍未实现。

## 2. 数据库设计

V1.0.0 创建 dpm_test_script；V1.1.0 新增 dpm_test_script_revision，并补充脚本与用例修订的固定引用。

- dpm_test_script：脚本编号、名称、启停状态、当前修订号和当前修订 ID。
- dpm_test_script_revision：脚本版本、语言、运行时、来源、源码/文件路径、入口、参数 JSON、修订说明和创建信息。
- dpm_test_case_revision.script_id：关联脚本主记录。
- dpm_test_case_revision.script_revision_id：固定关联脚本具体修订。

V1.1.0 会为迁移前已有脚本创建 V1 修订，并回填当前修订指针及测试用例修订引用。

## 3. 后端接口

统一前缀：/api/test-scripts

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/test-scripts | 分页查询，支持关键字、语言、启停状态 |
| GET | /api/test-scripts/{id} | 脚本详情及当前修订 |
| POST | /api/test-scripts | 新建脚本并创建 V1 |
| PUT | /api/test-scripts/{id} | 编辑脚本并创建新修订 |
| PUT | /api/test-scripts/{id}/enabled | 启用/停用脚本，不修改源码修订 |
| GET | /api/test-scripts/{id}/revisions | 查询脚本修订历史 |
| GET | /api/test-scripts/{id}/revisions/{revisionId} | 查询指定脚本修订 |

## 4. 字段与校验规则

- script_code：全局唯一。
- script_language：NODE、PYTHON、JAVA、HTTP。
- source_type：INLINE、FILE。
- INLINE：必须填写源码，长度不超过 100KB。
- FILE：必须填写安全相对路径；当前服务拒绝绝对路径、.、..、空路径段和目录穿越。HTTP 与 NODE v1 仅支持 INLINE；Python/Java 尚未实现 FILE 执行，未来启用时必须在受控脚本根目录下解析规范化路径，并验证最终路径未越界。
- entry_point：必填。
- arguments_json：必须是合法 JSON 对象或数组。
- 更新脚本时必须填写 change_note；每次更新新增修订，不覆盖历史修订。
- 并发编辑时锁定脚本主记录，按当前修订号递增。
- 启停状态变更不产生源码修订。

## 5. 前端页面

路由：/#/test-scripts

功能：
- 脚本列表、关键字/语言/启停状态筛选和分页。
- 新建、编辑脚本配置。
- 支持内联源码或受控文件相对路径。
- 启用/停用脚本。
- 查看修订历史及指定修订的源码、参数和修订说明。

页面需明确区分脚本保存与执行：保存只登记源码及修订；实际执行由测试轮次创建执行任务，再由对应 Runner 领取。NODE 目前执行 QuickJS WASM 受限 JavaScript 子集，不提供完整 Node.js API。

## 6. 与测试用例的关系

测试用例执行方式：
- MANUAL：人工执行。
- SCRIPT：固定脚本，必须关联已启用脚本及其当前修订。
- AI：由 ChatGPT 根据 aiInstruction 动态生成执行逻辑，不能同时关联固定脚本。

测试用例编辑生成新修订时，固定记录当时的 script_id 和 script_revision_id。测试轮次创建时，再将脚本修订信息复制进 case_snapshot，保证历史轮次不受脚本后续编辑影响。

## 7. 已实现的固定脚本执行器

- HTTP：独立 HTTP Runner，执行受限只读 DSL；目标主机绑定环境快照，支持 HTTP 状态码、响应头、JSON 路径和响应文本断言。第一阶段仅认证 NONE。
- NODE：独立 Node Runner 宿主进程，使用 QuickJS WASM 执行受限 JavaScript 子集；不暴露宿主 process、require、文件系统、子进程或网络 API；超时 5 秒、guest heap 32 MiB、栈 512 KiB；只支持 INLINE 和同步入口函数。
- Runner 均使用共享 Token 领取任务、租约心跳、事件上报和结果回传；服务端仅保存租约 Token 哈希。

## 8. 当前未实现

- Python、Java/JUnit 执行器；需要先确定可靠的操作系统级隔离或等效安全边界。
- 完整 Node.js 原生 API、npm 模块、文件/网络/子进程访问；不得直接暴露给当前 QuickJS guest。
- 浏览器自动化、截图、附件和测试报告。
- ChatGPT 自动生成脚本、执行步骤编排和人工确认闭环。
