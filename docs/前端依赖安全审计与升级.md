## 本地 npm 方案

T14s 原来只有 Node.js，可执行路径中找不到 npm。新增：
- `scripts/setup-portable-npm.ps1`：下载官方 npm 12.2.2 发布包，检查 npm 注册表提供的 SHA-512 integrity，然后解压到忽略目录 `.local/tools/npm-12.2.2`。
- `scripts/audit-dependencies.ps1`：同时审计 frontend 与 runner/node-runner，moderate 及更高级别告警会令脚本失败。
- `scripts/verify-local.ps1 -AuditDependencies -IncludeMySql`：将审计接入可选的本地完整回归。
- `frontend/package.json` 和 `frontend/package-lock.json` 原版备份存放于 `.local/backup/frontend-deps-before-audit-20261111`。

不修改系统 PATH，不全局安装 npm，不把便携工具提交到仓库。依赖安装使用 `--ignore-scripts`，不执行第三方包的生命周期安装脚本。
