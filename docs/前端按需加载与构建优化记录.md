> 日期：2026-11-11

## 1. 背景

原前端 `main.js` 使用 `app.use(ElementPlus)` 全量注册组件，并且 Router 同步引入全部业务页面。Vite 生产构建产生约 1,095.09 KB 的单个 JS 文件（gzip 355.60 KB），触发 500 KB 构建警告。

## 2. 改造内容

1. `frontend/src/main.js`：删除 Element Plus 全量注册，保留 Vue、Router 和现有全局样式。
2. `frontend/src/router/index.js`：全部 9 个页面改为 `() => import(...)` 的路由级懒加载。
3. `frontend/src/views/*View.vue`：8 个业务页面分别显式导入模板使用的 Element Plus 组件，不修改表单、接口和交互逻辑。
4. 使用 `v-loading` 的页面显式导入 `ElLoadingDirective as vLoading`，涵盖项目、版本、需求、测试用例、脚本库、环境、轮次和执行任务页面。
5. `frontend/scripts/verify-element-imports.mjs`：新增静态验证，检查模板标签、`v-loading`、全量注册回归及路由同步加载回归。
6. `scripts/build.ps1` 与 `frontend/package.json`：生产构建前执行静态验证，未通过时停止构建。
